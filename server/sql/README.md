# 手动 SQL 管理

1. 首次安装，在独立 MySQL 数据库执行 `001-init.sql`。脚本创建并使用 `rollcall` 数据库；改名时同步修改 CREATE DATABASE、USE 和 DB_URL。
2. 初始化脚本只能在空库执行一次。不要重复执行，也不要对已有业务库清表重建。
3. 后续新增 `002-*.sql`、`003-*.sql`，按编号执行，记录执行人、环境和时间；不要修改已执行脚本。
4. 已有数据库升级到包含“关于我们”的版本时，执行 `002-site-settings.sql`。应用不自动执行 SQL，无 Flyway、无 JPA 自动建表。
5. 升级前备份，先在副本验证；数据库回退需结合真实数据变更制定，不提供破坏性一键重置。

## 数据说明

- 固定角色保存在 `app_user.role`，不是可编辑权限树。
- `login_alias` 唯一主键统一学号/手机号命名空间，区分大小写；同账号两个字段相同只登记一次。
- `activity.round_no` 为当前轮次，历史轮次保存在 `draw_record.round_no`。
- `activity_student` 保存成员状态、活动内积分和宠物；移除不删积分。
- `activity.deleted` 软删除；历史记录保留但业务接口禁止访问。
- `score_ledger.draw_id` 唯一，积分与流水同事务提交。
- 数据库连接会话统一 UTC+8，前端展示中国标准时间。
- `site_setting` 保存公开网站内容；“关于我们”使用固定键 `about_us`，更新操作写入审计日志。

集成测试仅允许名称以 `_test` 结尾的独立库。每次测试创建独立前缀账号，不清空业务表。
